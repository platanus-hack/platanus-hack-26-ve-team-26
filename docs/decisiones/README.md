# Decisiones

Las decisiones que afectan a más de una persona o que alguien podría querer revertir sin saber por qué se tomaron. Una por archivo, corta.

- **Nombre:** `AAAA-MM-DD-<tema>.md` (por ejemplo `2026-10-24-websocket-y-no-webrtc.md`). La fecha evita choques de numeración entre los 4.
- Una decisión no se edita: si cambia, se escribe otra que la reemplaza y se marca la vieja como `reemplazada por ...`.
- Los jueces leen el repo con agentes: aquí se responde "¿por qué hicieron esto así?".

## Plantilla

```markdown
# <La decisión en una frase>

- **Fecha:** 2026-10-24 · **Quién:** Pastor y Juan · **Estado:** vigente

## Contexto

Qué problema había y qué restricciones.

## Decisión

Qué se eligió.

## Por qué

Las razones, con números si hay. Qué alternativas se descartaron y por qué.

## Consecuencias

Qué implica para las otras partes.
```
