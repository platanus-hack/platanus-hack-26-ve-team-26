## Contexto

Platanus exige una URL pública que el público pruebe durante el pitch. Vercel y Render solo se conectan a repos de cuentas propias, no a este repo de la organización. Además tenemos permiso de escritura, no de administrador: no podemos guardar secretos en el repo (para una GitHub Action con token) ni activar GitHub Pages.

## Por qué

Alternativas descartadas:

- **Segundo push URL en `origin`**, como propone el README de Platanus: `ship.sh` mergea en GitHub, así que el `main` nuevo nunca pasa por un `git push` local.
- **GitHub Action en este repo** que empuje al espejo o despliegue en Vercel: necesita un token guardado como secreto del repo, y eso pide permiso de administrador.
- **Espejo que se sincroniza solo** con una Action programada en el espejo: tarda minutos en ver cada cambio, y GitHub no garantiza la hora de las tareas programadas.
- **Deploy manual desde la Mac de Pastor:** solo una persona podría desplegar, y a Render no le sirve.
