# Modelos 3D de terceros

Modelos que la web dibuja sobre los objetos de los lugares (`physics/scenes/`): la física sigue usando cajas y cilindros, y `web/src/props.js` pone encima el modelo, escalado a esa misma forma. Los edificios rodean la calle de la landing (`web/src/landing/city.js`); son solo decorado, el robot no choca con ellos.
